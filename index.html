My projects

ResolveIQ: Agentic AI Ticket Resolution

2026View on GitHub →

An agentic AI system that picks up incoming ServiceNow tickets, finds similar past cases and drafts a resolution. It runs as a stateful LangGraph workflow (summarize, retrieve, generate, post) with Gemini, FastAPI and PostgreSQL/PGVector, with checkpointing, retries and authentication, and it’s deployed as a Docker container on Google Cloud Run. On 200 held-out tickets, it reached 85% human-verified resolution success.

LangGraphGeminiFastAPIPGVectorRAGDockerCloud Run

GPT-2 Architecture Reimplementation and Fine-Tuning

2026View on GitHub →

My deep dive into how language models really work. I implemented the GPT-2 architecture from scratch in PyTorch, covering tokenization, embeddings, multi-head self-attention and Transformer blocks, and built the training loop with AdamW. I then fine-tuned it from pretrained GPT-2 weights with a classification head to detect SMS spam, reaching 95.67% test accuracy on a balanced held-out set.

ISRO Chandrayaan-3 Q&A System

2026View on GitHub →

A question-answering assistant for Chandrayaan-3 mission documents. PDFs are split into chunks, embedded with all-MiniLM-L6-v2 and indexed in FAISS, and the top matches are passed to DistilGPT-2 through engineered prompts to generate grounded answers.
